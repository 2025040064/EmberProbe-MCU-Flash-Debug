# Keil 工程自动导入

## 目标与边界

导入 `.uvprojx` / `.uvproj` 后，按 Target 读取芯片和输出固件，避免逐项手动配置；提供从当前文件所属工作区读取工程的入口。不修改其他扩展的 Keil UVision Project 面板，不运行工程中的编译命令，不自动烧录或发布。

## 实现

- 独立服务解析 Keil XML，禁止 DTD，限制文件大小；只导入 Cortex-M 可识别目标。
- 单工程、单 Target 自动选取；多个候选交给用户选择，取消不修改配置。
- 输出文件严格来自所选 Target，验证 ARM ELF；不存在时提示先编译，不回退其他 Target 的固件。
- 优先识别已连接探针，Keil 驱动名称仅作无设备时的配置提示；不切换驱动。
- 当前文件用于缩小工程搜索范围；唯一关联 `.ioc` 自动填入。手动项折叠为高级设置。
- 新增行为测试，运行仓库要求的检查并记录限制，打包本地 VSIX 供安装。
